# Try the complete loop locally

No customer video is distributed. `tests/integration.py <new-temporary-directory>` creates explicitly synthetic media, performs a highlight reorder with captions/animated card/audio cleanup, makes a review page, then restores 0.3 seconds in a second version while preserving the first. Install the JavaScript dependency documented in the skill before running it.

For your own recording, ask your agent to read the installed skill. Keep source.mp4 and reviewed word timings in your project. Generate pause suggestions, inspect them, author a versioned EDL, render, then build the review page. `tests/browser.cjs` exercises the education and review interfaces against local servers; it is a developer test, not a command a coach needs to learn.

The synthetic test is a mechanical demonstration, not evidence of natural delivery, aesthetic quality, viewer response or human acceptance.
