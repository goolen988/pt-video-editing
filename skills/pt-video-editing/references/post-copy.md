# Post description and hashtags

Work from the final cut and the trainer's audience. Deliver a short ready-to-copy description plus a small relevant hashtag set, not a lecture about social platforms. When no brand voice is specified, use plain conversational wording. Explain only meaningful choices.

1. Identify the single useful takeaway and who it helps. Preserve qualifications in the spoken advice.
2. Write one short description that adds context or an appropriate next action rather than repeating all the subtitles. A second variation is useful only if the trainer asked for choice.
3. Pick tags people might actually search: the concrete topic, activity, audience and locality when relevant. Avoid finance-persona tags, irrelevant trending tags and unsupported claims that a particular count creates reach. Check current platform limits when an exact count is requested.
4. Align description, on-screen title and final video. Do not promise transformations, medical outcomes or a free asset the video/account does not provide.

Example (illustrative, not automatic copy): for a clip explaining shorter workouts through fewer repeated sets, “A shorter session starts with a clearer plan. Save this for your next workout.” Tags could centre on strength training and workout planning if those match the actual footage. If the video instead concerns recovery or exercise pain, do not reuse this example.

Save `post-copy.md` beside the delivered version. Publishing is a separate action; a drafted caption is not a published post or evidence of reach.
